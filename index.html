설치 파일 받기

무료 시험판 0.9Windows용

대본 그대로, 싱크까지 맞춘 자막

대본 PDF와 완성 영상을 넣으면 대본의 대사를 그대로 자막으로 쓰고, 음성 인식으로 싱크를 맞춥니다. 싱크가 애매한 줄만 따로 표시합니다.

설치 파일 받기 (Windows) 사용 순서
  • 영상은 PC에서만 처리
  • 회원가입 없이 사용
  • 자동 업데이트

자막핏이 하는 일

  • 자막 문구는 대본에서

    대본 PDF에서 대사만 골라 자막 문구로 씁니다. 따로 입력하거나 붙여 넣지 않아도 됩니다.

  • 싱크는 음성 인식으로

    음성 인식 결과를 대본과 맞춰, 대사가 시작하고 끝나는 시점에 자막을 배치합니다.

  • 인터뷰 쇼츠 만들기

    인터뷰 대본과 장면 클립을 넣으면 질문 자막, 구역 카드, 시작·마무리 화면을 넣어 세로 쇼츠로 만듭니다.

사용 순서

  1. 1

    대본과 영상 넣기

    '새 영상에 자막 달기'에서 대본 PDF와 자막 없는 완성 영상을 고릅니다. 원본 파일은 수정하지 않습니다.

  2. 2

    음성 인식·싱크 맞추기

    자동으로 진행됩니다. 4분 영상이 약 20초 걸립니다(NVIDIA 그래픽카드 PC 기준). 그래픽카드가 없으면 시간이 더 걸립니다.

  3. 3

    표시된 줄만 검토

    싱크가 애매한 줄만 따로 표시됩니다. 해당 구간을 재생해 보고, 맞으면 '맞아요'를 누르고 어긋나면 '조금 일찍'·'조금 늦게'로 조정합니다.

  4. 4

    MP4·SRT 내보내기

    자막 스타일 4가지 중 하나를 고르고, 필요하면 인트로·아웃트로·페이드를 넣어 MP4로 내보냅니다. 다른 편집 프로그램에서 작업할 때는 SRT 파일로 내보냅니다.

실제 작업 기록

악동꼬마 채널 《조선에 출동했습니다》 작업에서 측정한 값입니다. PC 사양과 영상에 따라 달라집니다.

  • 약 20초자막 초안 완성4분 안팎 영상, NVIDIA 그래픽카드 PC에서 5회 측정(12~24초)
  • 66줄 중 3줄직접 확인한 줄시즌2 10편 기준. 시즌2 4편은 55줄 중 5줄, 인터뷰 쇼츠는 13줄 중 0줄
  • 약 2분 15초인트로·아웃트로를 넣은 MP4 완성까지시즌2 10편 작업 1회 기록. 이전에 CapCut으로 자막을 붙여 넣을 때는 50분~1시간 걸렸습니다(제작자 기억, 측정값 아님)

기능

확인이 필요한 줄만 따로

음성 인식 결과와 대본을 맞출 때 확신이 낮았던 줄만 모아 보여 줍니다. 시즌2 10편은 66줄 중 3줄이었습니다.

맞아요 · 조금 일찍 · 조금 늦게
해당 구간을 다시 재생해 보고 싱크를 확정하거나 앞뒤로 옮깁니다.
글자 고치기 · 들린 대로 쓰기
배우가 대본과 다르게 말한 줄은 자막 문구를 바꿀 수 있습니다.
자막에서 빼기
편집에서 잘린 대사는 자막에서 뺍니다.
모든 줄 자세히 보기
표시되지 않은 줄도 전체 목록에서 열어 고칠 수 있습니다.

자막 스타일과 마무리

자막 스타일 4가지(테두리, 그림자, 굵은 글꼴, 테두리+그림자)를 실제 장면에 미리 그려 비교합니다. 글꼴은 본고딕(Noto Sans KR)입니다.

인트로·아웃트로
가지고 있는 인트로·아웃트로 영상을 등록하면 앞뒤에 붙입니다.
페이드
본편 시작과 끝이 1초 동안 서서히 밝아지고 어두워집니다.
장면 안내
대본에 적힌 '오후' 같은 시간·장소 안내를 화면에 넣습니다.
다른 화질로 바꾸기
자막을 맞춘 뒤 같은 영상의 다른 화질 파일(예: 4K)로 바꿔 내보낼 수 있습니다.

클립으로 인터뷰 쇼츠

인터뷰 대본 PDF와 인물별 장면 클립을 넣으면 1080×1920 세로 쇼츠로 만듭니다. 편집 프로그램이 없어도 됩니다.

클립 배치
대본에서 구역(질문을 받는 사람)을 찾고, 파일 이름으로 클립을 구역에 놓습니다. 틀리면 끌어서 옮깁니다.
질문 자막·구역 카드
질문은 자막으로 넣고, 구역이 바뀔 때는 '#1: 그날 트레이너의 속마음' 같은 카드를 넣습니다.
앞 화면·끝 화면
제목과 끝 문구는 대본에서 가져오며 직접 고칠 수 있습니다.
배경음악
가지고 있는 음악 파일을 깔 수 있습니다.

MP4와 SRT

자막을 입힌 MP4나 SRT 자막 파일로 내보냅니다.

MP4
H.264 영상입니다. NVIDIA 그래픽카드가 있으면 그래픽카드로 인코딩합니다.
SRT
다른 편집 프로그램에서 자막을 이어서 고칠 때 씁니다.
자막이 이미 들어간 영상
새 자막을 입히지 않고 SRT만 내보냅니다.
가지고 있는 SRT 넣기
다른 곳에서 만든 SRT를 영상에 입힐 수도 있습니다. 첫 화면 아래 링크에서 시작합니다.

도구마다 영상·음성을 처리하는 위치가 다릅니다. 각 회사 공식 안내에서 확인한 내용만 적었습니다.

2026년 10월 19일 각 회사 공식 안내 기준이며 바뀔 수 있습니다. 각 상표는 해당 소유자의 것이며 자막핏과 관계없습니다.

개인정보와 안전

음성 인식과 자막 입히기는 모두 사용자 PC에서 합니다. 인터넷은 아래 경우에만 씁니다.

  • 영상·대본·자막은 보내지 않음

    작업 파일은 PC의 작업 폴더에만 저장됩니다.

  • 처음 실행할 때 내려받기

    인식 모델(약 1.6GB)을 받습니다. NVIDIA 그래픽카드가 있으면 그래픽카드 부품(약 1.4GB)도 받습니다.

  • 서명된 업데이트만 적용

    실행할 때 새 판이 있는지 확인합니다. 전자 서명이 맞는 파일만 적용하고, 새 판이 켜지지 않으면 이전 판으로 되돌립니다.

  • 사용 통계는 동의한 경우만

    2026년 10월 27일부터, 동의한 경우에만 하루 단위로 만든 작업 수·완성 영상 수와 오류 종류를 보냅니다. 대사·파일 이름·영상은 보내지 않습니다.

  • 로그인은 선택

    계정 없이 모든 기능을 쓸 수 있습니다.

  • 원본 파일은 수정하지 않음

    대본과 영상 원본은 읽기만 하고, 결과물은 따로 저장합니다.

자세한 내용은 개인정보 처리방침에 있습니다.

설치 순서

  1. 설치 파일을 받습니다(약 108MB).
  2. 'Windows의 PC 보호' 창이 뜨면 '추가 정보'를 누르고 '실행'을 누릅니다. 아직 코드 서명 인증서가 없어서 뜨는 창입니다.
  3. 처음 실행하면 인식 모델을 내려받습니다. 인터넷 속도에 따라 몇 분 걸릴 수 있습니다.
  4. 지울 때는 Windows 설정 → 앱 → 자막핏 → 제거를 누릅니다. 만든 작업을 지울지 묻고, 기본은 남겨 둡니다.

자주 묻는 질문

다른 질문은 gunyoon0322@naver.com으로 보내 주세요.

무료인가요?

지금 시험판(0.9)은 무료입니다.

어떤 대본 파일을 넣나요?

PDF입니다. 대본의 글자를 읽어 대사를 고르므로 글자를 선택할 수 있는 PDF여야 합니다. 스캔한 이미지 PDF는 읽지 못합니다.

어떤 영상을 넣나요?

자막이 없는 완성 영상(MP4·MOV·MKV·M4V)입니다. 자막이 이미 들어간 영상은 SRT만 내보낼 수 있습니다.

대본과 다르게 말한 대사는 어떻게 되나요?

확인 화면이나 '모든 줄 자세히 보기'에서 '들린 대로 쓰기'나 '글자 고치기'로 바꿀 수 있습니다.

그래픽카드가 없어도 되나요?

됩니다. 음성 인식을 CPU로 하므로 시간이 더 걸립니다. 그래픽카드가 없는 PC의 소요 시간은 측정 중입니다.

영상이 인터넷으로 올라가나요?

아니요. 음성 인식과 자막 입히기는 PC에서 합니다. 인터넷을 쓰는 경우는 위 '개인정보와 안전'에 적었습니다.

로그인해야 하나요?

아니요. 계정 없이 모든 기능을 쓸 수 있습니다.

다른 편집 프로그램에서 이어서 작업할 수 있나요?

SRT로 내보내 불러오면 됩니다.

본편을 잘라 쇼츠로 만들 수 있나요?

아니요. 쇼츠는 인터뷰 대본과 장면 클립으로 만드는 인터뷰 형식만 지원합니다.

업데이트는 어떻게 받나요?

자막핏을 실행할 때 새 판을 확인해 받아 두고, 다음 실행 때 적용합니다.

지우려면 어떻게 하나요?

Windows 설정 → 앱 → 자막핏 → 제거를 누릅니다. 만든 작업을 지울지 묻고, 기본은 남겨 둡니다.
